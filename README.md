# Ang Ating Vargas

Clickable prototype for a participatory experience at the UP Vargas Museum (3rd floor).

- **Phone:** at 4 prompted stops, visitors photograph a piece and add an optional note. A Wrapped-style recap follows.
- **Projector 1:** scrapbook wall. The newest page is in front, and red threads link pages that share a pick.
- **Projector 2:** a grid of the latest pages, each with its own QR code to keep it.

Open `index.html` in a browser. The artworks, QR codes and other visitors are placeholders.
